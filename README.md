# Classifier

Классификатор файлов — один файл `index.html` (HTML + CSS + JS внутри).

## Хранение

Всё основное лежит в **IndexedDB** браузера (Chrome, Edge, Firefox, Safari):

- каталог (классификаторы, теги, список файлов и пути);
- содержимое добавленных файлов и заметок (blob).

Отдельный JSON на диске не нужен. В шапке по желанию:

- **Полный бэкап** (плоская оранжевая кнопка) — каталог + файлы из IndexedDB в **одну папку** на флешке (можно **продолжить после F5**) или в **один ZIP** (после обновления страницы ZIP оборвётся — только заново). Браузер предупредит, если закрыть вкладку во время бэкапа. Для `file://` не выбирайте Users/Desktop/проект;
- **Экспорт JSON** — только каталог без файлов;
- **Импорт JSON** — загрузить каталог из файла;
- **⚙ Настройки** — лимит размера файла для IndexedDB (по умолчанию 3 ГБ). Крупнее — только ссылка на файл, если браузер её даёт.

Добавление в IndexedDB и скачивание идут фоном; сверху — прогресс-бары.

Путь файла записывается при добавлении (что отдаёт браузер). Для заметок: `IndexedDB/Classifier/имя-файла`. Полный путь вида `C:\Users\...` страницам обычно недоступен.

## Интерфейс

- Сверху — выбор классификатора.
- Слева — теги-фильтры.
- У файла: **Скачать**, **Удалить**; теги под именем — крестик убирает тег, **+ тег** открывает форму выбора.
- Развернуть (▸) — предпросмотр текста, картинки, аудио, видео, PDF, **DOCX**.
- Старый **.doc** и **DjVu** — без предпросмотра (можно скачать).
- Добавление (на панели классификатора): **+** файл, **+T** текст, **+✎** рукопись; также drag-and-drop в область файлов.

## Запуск

Откройте `index.html` в браузере (двойной клик или перетащите в окно Chrome/Edge/Firefox).
